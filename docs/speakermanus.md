# Speakermanus – FreshFix UF (60 s)

Läs lugnt och tydligt, med ett leende i rösten. Tiderna följer filmens klipp (83 BPM).
Spela in allt i **en** fil som börjar exakt på 0:00 (använd filmen som referens i hörlurar),
spara den som `public/audio/voiceover.wav` och kör:

```bash
npm run audio && npm run render
```

Musiken sänks automatiskt där rösten hörs.

| Tid | Bild | Speaker |
| --- | --- | --- |
| 0:00–0:06 | Problemet | *Varje år slängs enorma mängder mat. Det påverkar både miljön och plånboken.* |
| 0:06–0:17 | Fakta | *En barnfamilj i Sverige slänger cirka hundratrettio kilo mat per år. Trettiofyra kilo per person. Det kostar en familj fem- till sextusen kronor om året.* |
| 0:17–0:24 | Lösningen | *Men tänk om det fanns ett enklare sätt att ta hand om maten? … Vi presenterar FreshFixer.* |
| 0:24–0:33 | Så fungerar det | *Aktivt kol och zeolit adsorberar oönskade lukter. Två material, ett smart filter. Enkelt att använda – enkelt att byta.* |
| 0:33–0:43 | Hållbarhet | *Behållaren i rostfritt stål är byggd för att användas igen – bara filterpåsen byts. Lokalt producerad i Uppsala, med smartare materialval. Vårt mål: mindre matsvinn.* |
| 0:43–0:49 | Varför vi | *Vi ser ett problem. Vi har en lösning. Vi vill göra skillnad. Vi är FreshFix UF.* |
| 0:49–1:00 | Avslut | *Vi har en lösning på ett problem som inte kan ignoreras – och vi är redo att ta nästa steg. Välj FreshFix UF till Alumninästet 2026.* |

Tips: säg "FreshFixer" som *fräsch-fixer*, alltså samma uttal som i ert företagsnamn.
